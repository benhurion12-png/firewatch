# Fusion v1

Расчёт в services/api/src/risk.ts. Вход — только датчики одного лесного участка. Используются реальные единицы °C и %RH и логический сигнал пламени. Нет вымышленной «вероятности FS24X» или измерений дыма.

## Формула

clip(x) = min(1, max(0, x))

- t = clip((T − 25) / 25)
- d = clip((50 − RH) / 40)
- rT = clip(dT/dmin / 3)
- rH = clip(−dRH/dmin / 5)
- F = 1 при свежем сигнале flame_detected, иначе 0
- R = round(20t + 15d + 15rT + 10rH + 10td + 30F)
- Если F = 1, R = max(90, R).

Каждый вклад округлён до 0,1 до итогового суммирования. При отсутствии пригодного HMP155 и активного пламени score=null. Отсутствие параметров не трактуется как измеренный ноль.

| Индекс | Уровень |
| --- | --- |
| 0–24 | NORMAL |
| 25–54 | WARNING |
| 55–79 | HIGH |
| 80–100 | CRITICAL |
| Неполный спокойный набор / нет пригодных данных | UNKNOWN |

Температура и сухость без пламени могут достигнуть HIGH, но не CRITICAL: их максимальный совместный вклад — 70.

## Время и качество

1. Пакет обязательно имеет часовой пояс; в будущем допускается максимум 5 секунд. Пакеты старше суток отбрасываются.
2. Свежесть — 120 секунд по measuredAt, не по времени доставки.
3. Latest выбирается по measuredAt. Поздний старый пакет не затирает новое состояние.
4. Последний fault делает канал непригодным: более старое успешное измерение не подставляется вместо него.
5. Данные обоих типов свежие и исправные, разница <=30 секунд: COMPLETE.
6. Один пригодный канал или рассинхронизация: PARTIAL. Ни одного: OFFLINE.
7. Неполное покрытие не получает успокаивающую метку NORMAL.
8. Скорость — линейная регрессия за 5 минут по measuredAt; минимум 3 точки и 30 секунд между первой и последней. Отрицательный температурный тренд и положительный тренд RH не увеличивают риск.

## Удержание и восстановление

Эскалация мгновенная. Для снижения предыдущих WARNING / HIGH / CRITICAL нужны COMPLETE и индекс ниже порога предыдущего уровня на 5 баллов в течение 60 секунд. Потеря данных прерывает восстановление. Метка риска и текущий числовой индекс показаны отдельно: в фазе восстановления CRITICAL может сохраняться при уже низком индексе, с объяснением в reasons.

Принятие события оператором не снимает риск и не меняет сенсорные показания. Старый сигнал пламени не удерживается навсегда после возвращения достоверных спокойных показаний: применяется правило восстановления.

## Тенденция

Прогноз на 5 минут ограниченно экстраполирует только неблагоприятные тренды T и RH, обрезает прогнозируемые значения диапазоном сенсоров и пересчитывает индекс. Только при COMPLETE и достаточной истории. Это не прогноз вероятности пожара, появления пламени, направления или площади распространения.

## Примеры

- 24 °C, 55 %RH, пламени нет, оба датчика свежие → 0 / NORMAL.
- 50 °C, 10 %RH, без тренда и пламени → 45 / WARNING.
- 52 °C, 10 %RH, рост +10 °C/мин и RH −20 %/мин → 70 / HIGH.
- Свежий FS24X с пламенем даже без HMP155 → не менее 90 / CRITICAL, PARTIAL.
- Оба датчика молчат более 120 секунд → UNKNOWN / OFFLINE; уже возникшая тревога сохраняется.
- После переназначения HMP155 его предыдущие показания не участвуют в новом участке.
